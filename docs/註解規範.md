# TradingLambda 註解規範

> 權威：EngineeringOS `eos-minimal/knowledge/comments.md` @ 0.1.5  
> 本專案宣告：`comment_verbosity: detailed`

## 為什麼是 detailed？

本專案是 **Lambda／Stream 教學**，註解要讓初學者看懂：

1. **【職責】** 這個方法在業務上做什麼  
2. **【技巧】** 用了哪個 Java 語法／API（Lambda、方法參考、Stream…）  
3. **【概念】** 為什麼這樣寫、和傳統 for 迴圈差在哪  

一般業務專案請改為 `brief`，避免註解過長。切換方式見公版 §7。

## 套用範圍

| 路徑 | 深度 |
|------|------|
| `src/main/java/**` | detailed |
| `src/test/java/**` | detailed（含要驗證的技巧） |
| `practice/**` | detailed（題目提示＋技巧提示） |
| `scripts/*.ps1` | 檔頭用途／何時跑／成功標準 |
