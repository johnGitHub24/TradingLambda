# TradingLambda 練習建議

> 衝突以 [TradingLambda-SPEC.md](../TradingLambda-SPEC.md) 為準。

## 目標

完成本練習後，你應能：用 Lambda 過濾／排序訂單、用 Predicate／Function／Consumer 表達意圖、用 Stream 做 filter／map／collect。

## 建議路線（約 1～2 小時）

| 步驟 | 動作 |
|------|------|
| 1 | 閱讀 `domain/Order` 與三個 Lab 的方法簽名 |
| 2 | 跑 `.\gradlew.bat check` 確認參考實作綠燈 |
| 3 | 打開 `practice/` 空殼，依註解自行實作（可先抄再改） |
| 4 | 對照 `src/test` 理解斷言意圖 |

## 題目對照

| Lab | 練習重點 |
|-----|----------|
| LambdaBasics | status 過濾、price 排序、格式化字串 |
| FunctionalInterfacesLab | 可成交 Predicate、名目金額 Function、收集 Consumer |
| OrderStreamLab | 買進＋PENDING、名目金額 map、總額／依 symbol 分組 |
