Labs — 三個實驗室

  • LambdaBasics：Lambda 過濾、排序、格式化字串。
  • FunctionalInterfacesLab：Predicate、Function、Consumer。
  • OrderStreamLab：Stream filter／map／collect 聚合。

Stream — 訂單資料流

  • 記憶體內 List<Order>；欄位含 side、status、quantity、price。
  • 典型鏈：filter（條件）→ map（轉換）→ sorted → collect（toList／groupingBy）。
  • 搭配 OrderSide、OrderStatus enum 做業務語意過濾。
