TradingLambda — 介面／操作文件

Java 21 Lambda／Stream 精簡練習（交易訂單情境）· JUnit 5 · Gradle（非 Spring Boot 服務）

本專案無 HTTP API，Swagger／OpenAPI 不適用。「API」= 三個 Lab 的公開靜態方法（src/main/java/com/trading/lambda/lab/），由 JUnit 5 測試作為契約；驗證入口 .\gradlew.bat check。

快速開始

cd d:\ClaudeCode\TradingLambda
.\gradlew.bat check   # 驗證入口（unit tests）

主要命令

  • 全套驗證：.\gradlew.bat check。
  • 只跑單元測試：.\gradlew.bat test；指定 Spec：--tests "*OrderStream*"。
  • Domain：精簡 Order／OrderSide／OrderStatus（com.trading.lambda.domain）。

產出物（練習空殼）

參考實作src/main/java/com/trading/lambda/lab/（lambda／functional／stream）
練習空殼practice/com/trading/lambda/practice/（自行填寫，不進主測試 classpath、不影響 check）
測試報告build/reports/tests/

驗證方式

  • 權威入口：.\gradlew.bat check 全綠（JUnit 5）。
  • 每個 Lab 公開方法皆有對應測試作為行為契約；練習時以測試回饋驗證自己的實作。
與 HTTP 專案的 docs/swagger.html 對齊之介面文件入口 · 非 HTTP 專案以 Lab 公開方法／測試契約取代 OpenAPI。
